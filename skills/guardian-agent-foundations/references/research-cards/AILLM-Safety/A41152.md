## Research question
Can a zero-shot, LLM-overseen agentic pipeline moderate text-to-image (T2I) prompts so outputs are safe *and* still helpful/faithful — avoiding blanket refusals, black images, or quality loss — including against semantic jailbreaks, text/image misalignment, and value/culture violations?

## Problem definition
T2I models (Stable Diffusion, etc.) can be driven, intentionally or inadvertently, to NSFW/culturally-inappropriate output. Existing defenses (keyword filters, image-level moderation, concept-erasure fine-tuning) fail on paraphrased/indirect prompts, are costly, degrade quality, or refuse outright. Three hard cases: (1) semantic jailbreaking (innocuous words like "zombie"/"Dita Von Teese" that yield unsafe images), (2) module misalignment (T2I cannot render negation/prohibition, e.g., "naked running is forbidden"), (3) value mismatch (context-dependent norm violations, e.g., pole dancing in a congress).

## System or model being studied
VALOR (Value-Aligned LLM-Overseen Rewriter): a modular moderation function F wrapping a T2I generator G, applied across four rewriting LLMs (Deepseek-7b-chat, Qwen1.5-1.8B-Chat, Zephyr-7b-beta, Llama-3.2-3B-instruct) and four T2I models (SDV1.4, SDXL, SDV3.5, PixArt-α).

## Threat model
- Adversary objective: induce NSFW / value-violating / policy-evading images.
- Adversary knowledge: black-box prompt-level (adversarial, ambiguous, value-sensitive prompts).
- Adversary access: user prompt input to the T2I service.
- Adversary capabilities: semantic jailbreaking, indirect/paraphrased phrasing, negation/prohibition framing, neutral-element combinations that produce unsafe scenes.
- Attacker budget: not quantified.
- Phase: inference/deployment.
- Targeted / untargeted: targeted unsafe-content generation.
- Digital / physical: digital.
- Adaptive / non-adaptive: non-adaptive w.r.t. VALOR (no attacker specifically adapted to defeat VALOR is evaluated).

## Trust assumptions
Trusts the moderation LLM to rewrite faithfully under category-specific system prompts, a sentence encoder for semantic/value similarity, a dependency parser (SpaCy) for intention detection, and a post-hoc image safety checker for verification/regeneration.

## Attack or failure mechanism
Unsafe outputs arise from single-modal (lexical) gaps, cross-modal misalignment (image model as "translator" that ignores negation), and machine–human value misalignment. Keyword filters miss semantic/indirect prompts; image moderation is expensive with false negatives; erasure/fine-tuning hurts quality/generalization.

## Proposed defense or method
Three-stage detect→respond→verify pipeline: ❶ Multi-granular detector Is_safe(p) = ¬(W∨S∨V): word-level blocklist W, semantic-level cosine similarity S vs unsafe reference phrases (threshold τs), value-level V requiring *both* a sensitive location and an inappropriate act to exceed τv. ❷ Intention classifier I(p) over a dependency graph flagging negation/prohibition cues (not/forbidden/illegal/banned) syntactically applied to unsafe objects. ❸ Category-specific zero-shot LLM rewrite (NSFW / VALUE / INTENTION system prompts) producing a safe, intent-preserving prompt that must pass a follow-up safety check; optional lightweight style-guided image regeneration (append safety suffix, e.g., "in illustration style") only if the generated image still fails the checker.

## Datasets and benchmarks
Two constructed datasets: Intent-452 (intention judgment) and Value-412 (value alignment). Also uses adversarial/ambiguous/jailbreaking-semantic prompt sets (I2P referenced). Baselines: SD post-processing safety checker; concept-erasing (SafeGen, ESD, MACE, RECE); training-free (SAFREE, SLD series). 4×A100 (40GB), Python 3.8.10, PyTorch 1.10.2.

## Evaluation methodology
Cross-product of 4 rewriting LLMs × 4 T2I models over Intention-Ambiguity, Value-Alignment, and Jailbreaking-Semantic settings; detection quality via ACC/FPR/FNR; safety via SAFE rate; fidelity/quality via CLIP score and LPIPS. Ablation ("Only Rewrite", "Baseline") reported.

## Metrics
ACC, FPR, FNR (detection); SAFE (% safe outputs); CLIP (prompt-image alignment, higher better); LPIPS (perceptual distance, lower better). Author note: higher ACC/SAFE/CLIP and lower FPR/FNR/LPIPS are better.

## Main findings
- Author claim: VALOR reduces unsafe outputs by "up to 100.00%" while preserving usefulness/creativity.
- Author claim (Table 1): high detection ACC (e.g., 97.8–100% on intention with Deepseek/Llama configs) and high SAFE rates across T2I models, with retained CLIP/LPIPS quality.
- Ablation (author claim): "Only Rewrite" reaches zero FNR but over-sanitizes (FPR = 100%); "Baseline" fails to detect (ACC = 37.1%); the multi-level design is needed for the safety/quality balance.

## Negative results
Some configurations show high FNR (e.g., Qwen1.5-1.8B intention FNR ~31–33% in Table 1), indicating the smaller rewriting LLM misses unsafe intent more often — safety is model-dependent. Value-level detection requires *both* location and act cues, which can miss single-cue violations (design trade-off).

## Limitations stated by the authors
Image post-guidance is "passive" and only dilutes unsafe content — it cannot replace semantic/value alignment; it is invoked only when necessary. The approach depends on predefined blocklists, reference phrase sets, and concept sets (L, A, U, B) that must be curated.

## Additional limitations identified during review
_(reviewer synthesis — clearly not author claims)_
- No adaptive attacker targeting VALOR itself (e.g., prompts crafted to survive rewrite) is evaluated; "up to 100%" is a best-case over settings, not a worst-case guarantee.
- Thresholds τs/τv, blocklist B, and reference sets are hand-tuned; generalization to unseen cultures/norms and languages is untested.
- Value judgments (what is norm-violating in which context) are encoded by the authors' curated concept sets — a subjective, potentially biased policy surface.
- SAFE/quality metrics partly rely on the same class of models being evaluated; no human study of rewrite faithfulness is reported in the extracted text.
- Rewriting can silently alter user intent (honesty risk) beyond what CLIP/LPIPS capture.

## Design implications
A layered detect→rewrite→verify guardrail that *rewrites toward intent* rather than refusing is a reusable pattern for helpful-and-harmless generation; separating lexical, semantic, and value/context checks catches distinct failure modes a single filter misses.

## Implementation implications
Combining syntactic (dependency-parse negation) detection with embedding similarity addresses the T2I "cannot render prohibition" failure; require rewrites to pass a second safety check and gate expensive image regeneration behind a post-hoc checker to control cost.

## Evaluation implications
Report detection FPR/FNR alongside output SAFE rate and fidelity (CLIP/LPIPS) so over-sanitization (FPR) is not hidden by high safety; include context/value-mismatch cases, not just explicit NSFW.

## Deployment implications
Suitable as a pluggable, retraining-free moderation front-end for hosted T2I services; smaller rewriting LLMs materially weaken safety (higher FNR), so model choice is a security parameter.

## Monitoring and incident implications
Log detector category decisions and regeneration triggers; monitor for prompts that repeatedly reach the image-verification/regeneration stage as signals of semantic-jailbreak attempts.

## Applicability boundaries
Findings apply to **text-to-image** prompt moderation, not to text-only LLM agents or tool-use security. It is a generative-model content-safety guardrail (adjacent to agent security via its LLM-agent rewriting mechanism), and the value/culture judgments are specific to the authors' curated norms and should not be treated as universal policy.
