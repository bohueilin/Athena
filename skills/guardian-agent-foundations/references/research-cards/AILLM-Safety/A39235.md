## Research question
How can incomplete multi-view clustering (IMVC) recover missing views without introducing imputation bias while maintaining cross-view semantic consistency and intra-cluster compactness, across varying levels of missingness?

## Problem definition
Real-world multi-view data often has missing views (sensor failures, corruption). Imputation-based methods suffer error propagation (bad imputations degrade later ones); imputation-free methods face instance misalignment, information imbalance, and assignment uncertainty as missingness grows.

## System or model being studied
DIMVC-HIA: (1) view-specific autoencoders + a view-shared clustering predictor producing soft assignments; (2) hierarchical imputation — first impute missing cluster assignments via cross-view label-aware contrastive similarity, then reconstruct missing latent features from intra-view, intra-cluster statistics (cluster prototypes); (3) an energy-based semantic alignment module (cluster-specific EBMs minimizing energy deviation from low-energy anchors); (4) a contrastive assignment alignment loss with entropy regularization for balanced, well-separated clusters.

## Attack or failure mechanism
No attack. The "vulnerability" the authors cite is benign error propagation in imputation — poor reconstructions distort structure and degrade subsequent imputations. This is a data-quality failure, not a security failure.

## Proposed defense or method
Not a security defense. Two-stage hierarchical imputation (assignments then features) plus dual alignment (energy-based compactness + contrastive cross-view consistency), trained end-to-end (L = L_REC + α·L_EBM + β·L_CAA).
