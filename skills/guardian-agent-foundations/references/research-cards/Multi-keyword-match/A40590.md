## Research question
How can in-context learning (ICL) be made effective for a fine-grained, out-of-distribution (OOD), low-resource task — Alzheimer's disease (AD) detection from narrative transcripts — where demos are semantically homogeneous and task cognition is weak?

## Problem definition
AD detection = binary classification (AD vs healthy control) from picture-description transcripts. Two bottlenecks: (i) limited task cognition (OOD, scarce closed-source data) fixed after pre-training; (ii) poor task perception because all participants describe the same scene, yielding homogeneous demos with weak text-to-label signal. Standard ICL saturates; Task Vector (TV) methods are ill-suited due to mismatched injection granularity/strength/position.

## System or model being studied
DA4ICL, a demo-centric anchoring framework: (1) Diverse and Contrastive Retrieval (DCR) selects an 8-demo main set under four criteria (semantic similarity/dissimilarity, length similarity/dissimilarity) then sub-demos for depth; (2) Projected Vector Anchoring (PVA) extracts fine-grained per-demo task vectors and projects them onto each main-demo's reasoning-token hidden state at every Transformer layer, modulating magnitude while preserving semantic direction (avoiding additive/replacement TV injection). Test-sample token is left unmodified.

## Trust assumptions
Trusts the retrieval corpus, the demo pool, and the base LLM's internal hidden states. Patient transcript data is assumed available and trusted; privacy is acknowledged as a reason for data scarcity but not addressed as a defense.

## Attack or failure mechanism
Not security. Addressed failures: ICL saturation (insufficient context width/depth), and TV pseudo-sample overfitting / semantic misalignment from additive or replacement injection into hidden states.

## Proposed defense or method
DCR (width) + PVA (depth). PVA normalizes each layer's TV to the layer's average L2 norm, computes projection onto the original hidden-state direction, and updates the hidden state with a layer-specific scaling factor γ, preserving direction and modulating magnitude across all layers so demo anchors persist through the residual stream.

## Main findings
DA4ICL achieves large, stable gains over both ICL and TV baselines across three AD benchmarks (author claim). Demo-centric, full-layer projected anchoring outperforms test-centric single-layer TV injection for this fine-grained OOD task.

## Negative results
Author-identified failure of prior methods (not of DA4ICL): standard ICL saturates and TV methods overfit pseudo-samples / distort semantics; these motivate the method. No explicit DA4ICL failure case in the extracted text.

## Design implications
For agent security this illustrates a general point: manipulating internal hidden states across all layers is a powerful control channel — the same mechanism that steers task adaptation could be abused (activation steering / latent injection) if an attacker gains white-box access. Systems exposing hidden states should treat that as a sensitive capability.

## Implementation implications
Layer-wise projected steering (magnitude-only, direction-preserving) is a comparatively conservative intervention vs additive replacement — a useful pattern if activation-level guardrails are ever built, but requires model-internal access.

## Evaluation implications
Highlights that homogeneous/low-diversity contexts degrade ICL — relevant to red-teaming demonstration-based defenses where an attacker could exploit demo homogeneity.

## Deployment implications
White-box requirement makes this inapplicable to hosted/API agents; no safety controls defined.
