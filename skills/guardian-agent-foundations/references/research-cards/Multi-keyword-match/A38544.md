## Research question
How can a multimodal sequential recommender capture dynamically evolving user interests across modalities while handling modality imbalance (missing modalities) and interaction-data sparsity?

## Problem definition
Given user interaction sequences with per-item ID, textual, and visual content plus timestamps, predict the next item a user will interact with. Three challenges: (1) cross-modal interactions that evolve with user intent over time; (2) modal incompleteness (e.g., missing images/descriptions); (3) sparse/short interaction sequences (many of length 5–9).

## System or model being studied
DuAF-MAT, with three components: (1) Dual-Aware Adaptive Fusion (DuAF) — user- and time-aware modality weighting; (2) Modality Adversarial Training with Mixture-of-Experts (MAT-MoE) — a WGAN-style generator/discriminator (with gradient penalty) that reconstructs missing modality (visual) embeddings via expert routing conditioned on item category; (3) Multi-Supervised Contrastive Learning (MSCL) combining Cross-modal Sequence Contrastive Learning and Virtual Sequence Contrastive Learning. Sequence encoder is SASRec; text from BERT [CLS], images from ViT (frozen features). This is a recommender-system representation model, not a security system.

## Trust assumptions
Assumes benign data. "Adversarial training" here is generative-adversarial (WGAN) for embedding reconstruction — a min-max game between generator and discriminator for realism, NOT a security threat model. No trust boundary, poisoning, or privacy assumptions discussed.

## Attack or failure mechanism
No attack. Failure modes addressed are non-adversarial: modality missingness (naive zero/random init produces poor embeddings) and data sparsity (short sequences under-specify user interest).

## Proposed defense or method
Not a security defense. MAT-MoE uses adversarial (WGAN) learning to reconstruct missing visual embeddings; MSCL uses contrastive objectives and virtual-sequence augmentation to combat sparsity.
