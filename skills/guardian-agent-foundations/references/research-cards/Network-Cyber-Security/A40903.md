## Research question
Can secret messages be embedded into natural text for covert communication **without modifying the cover text at
all**, so that stego text is statistically/semantically/perceptually identical to normal text and thus escapes
steganalysis ("perfect security")?

## Problem definition
Prior linguistic steganography (LS) is content-transformation-based: it embeds bits by substituting synonyms,
transforming syntax, or steering generation. Any such transformation introduces subtle detectable deviations
between stego and cover text (statistical, semantic, perceptual), leaving clues for steganalysis. The paper reframes
the problem as: establish a set of variable steganographic coding functions H = {h0, h1, …} that map the SAME
unmodified cover word to different secret values, so the carrier text is never altered.

## System or model being studied
CLstega (Content-preserving Linguistic steganography). Built on a masked language model (MLM). Three components:
(1) Augmented Masking — locate/mask high-entropy non-functional embedding positions; (2) Dynamic Distribution
Steganographic Coding — derive target prediction distributions that encode secret bits; (3) Controllable
Distribution Transformation — fine-tune the MLM on a constructed labeled-masked-sentence dataset so that at each
embedding position the fine-tuned "target MLM" reproduces the target distribution, from which the receiver decodes
the message directly from the unmodified cover text.

## Trust assumptions
Sender and receiver share the fine-tuned target MLM (and masking/coding protocol) as a secret key-equivalent. The
cover text is genuine natural text. Security rests on the claim that, because content is unchanged, the observable
distribution of stego text is identical to cover text (KL(Pc‖Ps) → 0, per the paper's Figure 2 annotation).

## Attack or failure mechanism
Failure being eliminated: content-transformation LS must pick a candidate that depends on the secret bits, so the
carrier content varies with the payload, producing distributional shift that steganalysis exploits. CLstega removes
the transformation, so (author claim) no such shift exists.

## Proposed defense or method
Content-preserving paradigm + CLstega. Instead of h : CW ↔ M over transformed candidates, it uses H = {h0,h1,…} :
we → M applied to the fixed cover word we; embedding selects the coding function (realized as a fine-tuned target
distribution) rather than changing the word. Augmented masking targets high-entropy positions (nouns/verbs) whose
MLM distributions are easiest to reshape.

## Additional limitations identified during review
_(reviewer synthesis — not author claims)_
- "Perfect security" is asserted from the argument that content is unchanged, but the fine-tuned target MLM must be
  shared and reproducibly evaluated by the receiver; the security of the SYSTEM depends on secrecy of that model and
  protocol, which is a key-management problem not analyzed in the visible text.
- Fine-tuning the MLM to force target distributions could itself perturb the receiver's model behavior; whether an
  adversary who obtains the target MLM can distinguish it from a normal MLM (model-level steganalysis) is not
  addressed in the excerpt.
- No adaptive steganalyzer trained specifically against CLstega is shown in the extracted text, so robustness under
  adaptive detection is unverified here.
- Capacity is bounded by the number of maskable high-entropy positions; long payloads may need long covers.

## Design implications
Demonstrates that covert channels can be built on top of an ordinary-looking LLM/MLM output stream WITHOUT visibly
altering text — relevant to defenders as a data-exfiltration/covert-channel technique an agent or insider could use
over model outputs. Detection cannot rely on lexical/statistical text anomalies alone.

## Implementation implications
Because the stego signal lives in the (private) target distribution rather than the text, network/DLP filters that
inspect text content would not flag it. Controls must instead govern which fine-tuned models are permitted and
monitor for anomalous fine-tuning of served MLMs.

## Evaluation implications
Evaluating anti-steganalysis claims requires adaptive detectors (steganalyzers trained on the specific scheme) and
model-level detection (distinguishing the fine-tuned target MLM); text-only steganalysis is insufficient to falsify
a content-preserving scheme.

## Deployment implications
As an exfiltration vector, it argues for provenance/attestation of the models an agent is allowed to load and for
treating "innocuous" natural-language outputs as a possible covert channel in high-assurance settings.

## Monitoring and incident implications
Monitor for (a) deployment of unauthorized/fine-tuned MLMs, (b) matched sender/receiver model sharing, since the
channel is invisible at the text layer. Traditional content-inspection logging will not capture the payload.

## Applicability boundaries
Scope: text covert communication and steganalysis resistance. It is a steganography paper, not an agent-security
paper; its direct relevance to LLM-agent security is as an offensive covert-channel/exfiltration primitive over
model outputs. Do NOT generalize the "perfect security" claim beyond the tested (and, in this excerpt, not fully
visible) steganalysis threat model.
