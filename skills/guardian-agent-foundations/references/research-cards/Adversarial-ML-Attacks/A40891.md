## Research question
Can visual backdoor activations in Multimodal LLMs (introduced via Fine-Tuning-as-a-Service poisoning) be detected at INFERENCE time, in a black-box setting, without model parameters/architecture, retraining, or clean reference data?

## Problem definition
FTaaS lets users upload data to fine-tune vendor MLLMs; an adversary can slip in poisoned samples (visual trigger + fixed target response) so the returned model behaves normally but emits attacker-controlled outputs when the trigger appears (dangerous in autonomous-driving/medical settings). Training-time defenses need retraining; existing inference-time defenses need extra data, domain knowledge, generative models, or clean references — often unavailable in FTaaS.

## System or model being studied
MLLM = vision encoder f_v + projection g + LLM backbone L_θ, producing a = L_θ(g(f_v(v)), q). FTaaS fine-tuning (LoRA). Studied models: LLaVA-v1.5-7B, InternVL2.5-8B. Backdoor: BadNet-style visual trigger with a fixed target response (e.g., "I can't answer this question.").

## Threat model
- Adversary objective: implant a backdoor so that for any query q, presence of visual trigger v_trig forces a fixed target response a†, while clean inputs behave normally.
- Adversary knowledge/access: can inject a poisoned subset D̃ ⊂ D_train into the FTaaS fine-tuning data (data-poisoning access); does not need inference-time access.
- Adversary capabilities: craft visual triggers, pair with target responses.
- Attacker budget: a subset of poisoned fine-tuning samples.
- Phase: training / fine-tuning for implantation; inference for activation.
- Targeted / untargeted: targeted (fixed attacker-chosen response).
- Digital / physical: digital.
- Adaptive / non-adaptive: BadNet-style triggers evaluated; an attacker adapting the trigger to evade text-perturbation detection is not the central evaluation.
- Defender: the model PROVIDER; black-box detection using only image v, prompt q, output a; must uphold Harmlessness/Helpfulness/Honesty (3H).

## Trust assumptions
The fine-tuning data provenance is untrusted (FTaaS decouples users from training/data). The deployed model may be backdoored. The defender trusts only its own inference-time access to inputs/outputs (no white-box weights, no clean reference set).

## Attack or failure mechanism
Empirical analysis shows a visual trigger creates a "shortcut" mapping: the model's decision becomes dominated by visual cues, so f_θ(v_trig, q) ≈ f_θ(v_trig, q′) for any q, q′. This manifests as (1) abnormal insensitivity to textual perturbation and (2) abnormally stable, overconfident outputs. Layer-wise analysis (Fig. 2) shows poisoned samples induce higher answer-token attention to visual tokens than clean samples (modality attention shift).

## Proposed defense or method
Trap on Text (ToT) — inference-time, model-agnostic detection. Apply controlled semantic perturbations to the text prompt (random token replacement, q̃), run inference on original and perturbed prompts, then jointly test two signals:
1. Textual Semantic Consistency (TSC): compute overlapping phrases between outputs a and ã; TSC=1 if significant overlap persists (backdoor-like invariance).
2. Confidence Drift Gap (CDG) = |H(a) − H(ã)|, the change in average output entropy; clean samples show large CDG (uncertainty rises under perturbation), backdoored samples show small CDG (abnormally stable confidence). Flag backdoor if CDG < τ_cdg.
Combining TSC + CDG distinguishes trigger activations from benign behavior without retraining, white-box access, or clean data.

## Datasets and benchmarks
Models: LLaVA-v1.5-7B, InternVL2.5-8B (LoRA fine-tuning). Downstream datasets: ScienceQA, IconQA. Attack: BadNet (image trigger + fixed target); the paper evaluates across multiple architectures, datasets, and attack scenarios.

## Evaluation methodology
Fine-tune MLLMs with poisoned data; run ToT at inference; measure attack mitigation (reduction in attack success) and preservation of clean accuracy. Supporting analyses: layer-wise visual-attention proportion (Fig. 2), average output entropy vs. text-perturbation ratio (Fig. 4).

## Metrics
Attack Success Rate (reduction), clean accuracy; behavioral diagnostics: visual-attention proportion, output entropy / confidence drift, semantic-overlap counts.

## Main findings
- Author claim: two robust inference-time signatures of backdoored MLLMs — insensitivity to textual perturbation and stable overconfidence under visual triggers.
- Author claim: ToT achieves substantial attack-success reductions while maintaining high clean accuracy across multiple MLLM architectures, datasets, and attack scenarios.
- Empirical: backdoored samples show higher visual-token attention (modality shift); clean samples' entropy rises with perturbation while backdoored samples stay confident.

## Design implications
Backdoor activation leaves behavioral fingerprints (modality-attention shift, text-insensitivity, overconfidence) usable for black-box, inference-time guardrails — a practical monitor for FTaaS/third-party-model supply chains where weights are opaque.

## Implementation implications
A provider can wrap deployed MLLMs with a lightweight perturb-and-compare detector needing only I/O access; suits black-box, resource-constrained serving. Multiple forward passes and threshold tuning are the main implementation costs.

## Evaluation implications
Inference-time backdoor defenses should be stress-tested against ADAPTIVE triggers and measured for false-positive rate on confident benign inputs, not only attack-mitigation on BadNet-style triggers.

## Deployment implications
Directly relevant to FTaaS / model-marketplace supply-chain risk: consumers of fine-tuned MLLMs can screen for trigger activation without vendor cooperation. Residual risk: adaptive/未seen trigger types and FP-induced availability loss.

## Monitoring and incident implications
ToT is itself a runtime monitor / trigger-detection mechanism; flagged samples can be quarantined or routed to human review. Attention-shift and confidence-stability are candidate telemetry signals for backdoor incident response.

## Applicability boundaries
Scope: visual backdoor detection in MLLMs under FTaaS. Core to LLM/agent security (supply-chain backdoors, multimodal trigger detection). Should NOT be generalized to non-trigger data poisoning, unimodal text backdoors without visual dominance, or treated as a guarantee against adaptive attackers.
