## Research question
Can an attacker implant a stealthy, trigger-activated backdoor into a pre-trained open-vocabulary object detector (OVOD) purely through lightweight multi-modal prompt tuning during downstream adaptation — without retraining base weights or poisoning pretraining data?

## Problem definition
OVODs (GLIP, Grounding DINO) detect arbitrary categories from text prompts and are being adopted in autonomous driving, robotics, and surveillance. Their backdoor security is unstudied. Classical backdoors require poisoning large pretraining data — impractical for publicly released OVODs. The paper targets the realistic setting where users outsource lightweight prompt-tuning adaptation to a third party, exposing a new prompt-tuning attack surface.

## System or model being studied
Primary victim: Grounding DINO (Swin-Transformer image encoder + frozen BERT text encoder + cross-modality layers); also demonstrated on GLIP. Method: TrAP (Trigger-Aware Prompt tuning) — a learnable visual patch trigger jointly optimized with learnable prompt tokens inserted into BOTH the vision branch (VPT-Deep-style prompts per transformer layer) and the text branch (CoOp/CoCoOp-style shared context Q plus an image-conditioned meta-net h(·) producing a trigger-aware context vector). All layers except prompt embeddings and h(·) are frozen. A curriculum strategy progressively shrinks the trigger size across epochs for stealth.

## Threat model
- Adversary objective: implant a backdoor so that a triggered object is (OMA) misclassified to a target class, or (ODA) suppressed from detection, while clean-input behavior (mAP) is preserved.
- Adversary knowledge: white-box access to the pre-trained model during the outsourced prompt-tuning adaptation.
- Adversary access: performs the adaptation on the user's (Bob's) small annotated downstream dataset (a few hundred examples); controls prompt tokens, meta-net, and the visual trigger; returns a poisoned model F_poisoned.
- Adversary capabilities: joint optimization of visual trigger + multi-modal prompts; curriculum trigger-shrinking; identical trigger across all images/objects.
- Attacker budget: lightweight — no base-weight retraining, small downstream dataset.
- Phase: training-time backdoor injection during adaptation; activation at inference.
- Targeted / untargeted: targeted (OMA to a specified class; ODA suppresses target-class objects); paper notes extension to Object Generation Attacks.
- Digital / physical: digital patch stamped on images, motivated by physical stickers (e.g., sticker on an ambulance); physical realizability is motivational.
- Adaptive / non-adaptive: no adaptive backdoor-defense evaluation in the visible text.

## Trust assumptions
Assumes the increasingly common deployment pattern of outsourcing model adaptation (third-party cloud libraries) to an untrusted party who returns a tuned model the user then deploys, trusting it because clean-data accuracy looks normal. The trigger is a fixed visual patch overlaid on target objects.

## Attack or failure mechanism
OVOD detection is driven by alignment between image object-queries and text (class-name) embeddings; class confidence is a similarity score. TrAP forges a strong trigger→behavior association by perturbing BOTH modalities: vision prompts modulate visual features at each layer; text prompts (plus image-conditioned meta-net token) shift class embeddings. Manipulating the similarity/confidence lets the trigger push confidence toward a wrong class (misclassification) or below detection threshold (disappearance). Curriculum learning starts with large triggers (easy to learn) and shrinks them to small, stealthy patches usable at inference. Uni-modal (vision-only or text-only) prompting is reported weaker than joint multi-modal tuning.

## Evaluation methodology
Compares TrAP against vision-only and text-only prompting variants; evaluates both OMA and ODA objectives on Grounding DINO and GLIP; measures clean-image performance (mAP) vs the zero-shot setting; ablates the curriculum trigger-shrinking. Quantitative tables are in the truncated portion.

## Metrics
Attack Success Rate (ASR) for misclassification and disappearance; clean-data mAP (utility). Exact values not in the extracted text.

## Main findings
- Author claim: TrAP achieves high ASR for both object misclassification and object disappearance on Grounding DINO and GLIP, while *improving* clean-image downstream mAP relative to zero-shot.
- Author claim: jointly tuning both vision and text branches yields significantly stronger attacks than uni-modal prompting.
- Author claim: curriculum-based trigger shrinking enables effective activation with small (stealthy) trigger patches at inference.
- Author claim: first demonstration of backdoors on OVODs via prompt tuning (new attack surface).

## Negative results
Uni-modal (vision-only / text-only) prompt tuning is reported as a weaker attack than multi-modal TrAP — an implicit negative result motivating the joint design. No other negative results are visible.

## Design implications
Parameter-efficient adaptation (prompt tuning) is itself an attack surface: a modular, lightweight adapter can carry a hidden backdoor even when base weights are untouched and clean accuracy improves. Multi-modal models are more exposed because a trigger can be entrenched through both visual and textual representation paths.

## Implementation implications
Treat outsourced/third-party adaptation adapters as untrusted supply-chain artifacts: verify adapter provenance, scan tuned models for trigger-synthesis/backdoor signatures before deployment, and prefer in-house adaptation for safety-critical detectors. Consider repulsive/robust prompt-tuning and patch-agnostic defenses (cited but untested here).

## Evaluation implications
Backdoor red-teaming for OVODs should cover multi-modal prompt-injected backdoors (not only data-poisoning), both OMA and ODA objectives, small stealthy triggers, and clean-utility preservation — and must include defense/detection baselines to substantiate stealth claims.

## Deployment implications
For autonomous driving, robotics, and surveillance, a backdoored detector could, on a physical trigger, misclassify or "disappear" critical objects (e.g., an ambulance) while passing normal validation. Adapter integrity and detector output monitoring become safety-critical controls.

## Monitoring and incident implications
Monitor for anomalous confidence collapses/label flips co-located with recurring visual patches; retain input frames for forensic trigger analysis; maintain a signed inventory of which adapter/prompt-tuning artifact is loaded so a compromised adapter can be traced and rolled back.

## Applicability boundaries
Adjacent to agent security: it concerns vision-language *detector* security and the outsourced-adaptation (supply-chain) threat, transferable to any prompt-tuned multimodal component an agent relies on for perception. It is NOT about LLM prompt-injection or tool/MCP security directly. Generalize the "prompt tuning is a backdoor vector" lesson broadly; treat specific ASR/mAP claims as excerpt-limited.
