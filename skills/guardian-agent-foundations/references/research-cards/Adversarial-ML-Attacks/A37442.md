## Research question
Can universal adversarial perturbations (UAPs) be learned on an accessible pretrained multimodal LLM (MLLM) and transferred, black-box, to unknown downstream multi-image MLLMs — succeeding even when only a subset of the images in an inference instance is perturbed and the attacker cannot control image count or order?

## Problem definition
Prior adversarial attacks on vision-language models are (a) single-image, (b) largely white-box (assume gradients of the fine-tuned target), and (c) instance-specific, requiring re-optimization per input and typically requiring every image to be perturbed. These assumptions break in realistic multi-image settings (e.g., a model ingesting a webpage or ad images), where the attacker perturbs only some images and does not know the target model/task. The paper defines the task of learning a fixed set of UAPs that attack multi-image MLLMs under these constraints.

## System or model being studied
Multi-image MLLMs (open-source examples named: Mantis, VILA; single-image/multi-capable examples cited: LLaVA-NeXT, Idefics, GPT-4V, Gemini). Perturbations are learned on a frozen surrogate pretrained MLLM and transferred to black-box targets. Tasks: multi-image VQA and image captioning over multi-image benchmarks.

## Threat model
- Adversary objective: cause incorrect image–prompt associations / erroneous responses on multi-image MLLM inference (misclassification of which images satisfy a query, corrupted captions). Untargeted mis-prediction is the primary framing.
- Adversary knowledge (white/gray/black-box): black-box on the target — no knowledge of target architecture, weights, downstream task, or training process. Learns UAPs on a separate accessible surrogate pretrained MLLM.
- Adversary access: can inject perturbed images into the input stream (e.g., posting perturbed images online, serving adversarial ad images) but cannot access the target model or its gradients.
- Adversary capabilities: perturb only a subset k < M of the M images in an instance; cannot control how many images are ingested or in what order.
- Attacker budget: l∞-bounded perturbation, ∥δ∥∞ ≤ ε (ε value not stated in the extracted text); a fixed number k of universal perturbations.
- Phase: inference (perturbations applied at query time; learned offline on surrogate).
- Targeted / untargeted: primarily untargeted (reduce probability of correct token, increase wrong tokens); no explicit targeted-string objective.
- Digital / physical: digital (web-delivered images).
- Adaptive / non-adaptive: non-adaptive with respect to any specific deployed defense; no adaptive-defense evaluation described in the extracted text.

## Trust assumptions
Assumes the target ingests attacker-influenceable images from an untrusted channel (web, social media, ads) and that a frozen public pretrained backbone is a good enough surrogate for transfer. Assumes self-attention dynamics learned on the surrogate transfer to unseen downstream MLLMs.

## Attack or failure mechanism
LAMP optimizes UAPs (MLLM frozen) via five losses: (1) adversarial language-modeling loss — reduce probability of the correct next token; (2) adversarial hidden-states loss — maximize cosine distance between clean and adversarial decoder-layer hidden states; (3) adversarial attention loss via a relaxed Pompeiu–Hausdorff distance — maximize worst-case divergence between head-averaged clean vs adversarial attention weights; (4) a novel "contagious" loss — encourage clean image tokens to attend to perturbed tokens so adversarial effect spreads to un-perturbed images ("green"/clean samples); (5) index-attention suppression loss — suppress attention from image tokens to their positional index text tokens, yielding position-invariant (reorder-robust) attacks. The contagious objective is the key mechanism enabling a fixed number of perturbed images to corrupt a variable-size instance.

## Design implications
Multi-image ingestion is a distinct attack surface: defenses that assume "the adversarial image is the whole input" or "all images must be perturbed" underestimate the threat. Cross-image attention is a contagion channel — perturbed tokens influence clean tokens — so per-image sanitization is insufficient; joint cross-image consistency checks are needed.

## Implementation implications
Systems that assemble multi-image contexts from untrusted sources (agents browsing the web, RAG over image galleries, ad-serving pipelines feeding MLLMs) should treat any single untrusted image as potentially able to corrupt the interpretation of co-presented trusted images. Position/order-invariance of the attack means shuffling image order is not a mitigation.

## Evaluation implications
Robustness benchmarks for MLLMs should include multi-image, subset-perturbation, and image-reordering conditions, and report ASR as a function of the fraction of perturbed images — not just the all-images-perturbed regime.

## Deployment implications
For deployed multi-image MLLM services, treat cross-image attention as an untrusted-influence channel; consider provenance/isolation between images from different trust domains before joint attention.

## Monitoring and incident implications
Monitor for anomalous cross-image attention concentration and hidden-state divergence relative to per-image clean baselines; unexplained sensitivity of clean-image answers to co-submitted images is a candidate detection signal.

## Applicability boundaries
Findings apply to multi-image vision-language MLLMs at inference. They should NOT be generalized to text-only LLM prompt injection, to tool/agent-action security, or to single-image robustness conclusions. The contagion mechanism is specific to shared self-attention over interleaved image tokens.
