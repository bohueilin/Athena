## Research question
When a user of a machine-unlearning API can query BOTH the original and the unlearned model ("dual-view"), does the pair leak more membership information about *retained* (non-forgotten) data than either model alone — and can a dedicated attack exploit it?

## Problem definition
Prior unlearning-privacy work studies leakage of *forgotten* data and treats API users as victims. This paper flips it: the user who requests unlearning (and legitimately accesses before/after models to verify deletion) becomes an adversary against the privacy of *retained* data. The gap: no dedicated attack for retained-data membership under the dual-view setting.

## System or model being studied
Image classifiers under machine unlearning (exact and approximate). Example analysis uses ALLCNN on CIFAR-10 unlearning 5% of points; broader experiments across "diverse datasets and model architectures" (ResNet etc.). The adversary observes model outputs θo(x) and θu(x).

## Threat model
- Adversary objective: infer membership status of samples in a target set — retained (Dretain, members) vs. validation (Dval, non-members) — i.e., non-forgetting inference.
- Adversary knowledge: black-box outputs; knows the data distribution D, the training and unlearning procedures, and the model architecture, but NOT the model parameters.
- Adversary access: dual-view — can query both the original model θo and the unlearned model θu (realistic: users verify deletion). Can request removal of a forgotten set Df.
- Adversary capabilities: train shadow original/unlearned model pairs; compute the proposed UCD metric; run a likelihood-ratio test with a fixed threshold (no attack-model training required).
- Attacker budget: K shadow dataset pairs; no per-sample shadow-model generation (unlike LiRA).
- Phase: deployment / inference (post-unlearning querying); leverages the post-training unlearning step.
- Targeted / untargeted: membership inference (per-sample decision) over a target dataset.
- Digital / physical: digital.
- Adaptive / non-adaptive: exploits an intrinsic asymmetry of unlearning; not framed against an adaptive defender.

## Trust assumptions
The unlearning interface is trusted to let users confirm deletion (dual access). This legitimate access is the very attack surface: comparing pre/post outputs.

## Attack or failure mechanism
Information-theoretic framing: define Privacy Knowledge Gain(Dt) = I(MDt; so, su) − I(MDt; s) — the extra membership info from dual-view vs. single-view. Theorem 1: Gain > 0 iff the behavioral impact δ(Dt) of unlearning is statistically different for members vs. non-members. Root cause (author claim, supported by influence-function analysis via Koh & Liang, WoodFisher Hessian approximation): unlearning changes predictions on *unseen* (non-member) data more than on well-memorized *member* data (asymmetric impact). DVIA operationalizes this with UCD ∆(x,y) = θu(x)y − θo(x)y (confidence change on the true label), fits member/non-member Gaussians from K shadow pairs, and classifies via a likelihood ratio against a fixed threshold Λ (Algorithm 1). UCD in black-box mirrors white-box influence scores (Figs. 2–3).

## Proposed defense or method
No defense proposed; the paper references differential-privacy tooling (DP-SGD/Opacus) in related work as background mitigation, not evaluated here as a countermeasure.

## Datasets and benchmarks
CIFAR-10 (ALLCNN illustrative analysis), plus "diverse datasets and model architectures" (SVHN and others referenced; ResNet). Unlearning methods: exact (retrain) and approximate (e.g., gradient-based / SalUn / Descent-to-Delete families referenced).

## Evaluation methodology
Influence-score analysis (top-|influence| examples for non-forgotten vs. unseen); density comparison of influence vs. UCD; DVIA membership-inference performance across datasets/architectures (detailed result tables truncated in extract). Shadow-based Gaussian fitting; likelihood-ratio inference with fixed threshold.

## Metrics
- Privacy Knowledge Gain (mutual-information advantage of dual-view).
- Membership-inference performance of DVIA (attack accuracy / advantage; specific numbers truncated in extract).
- UCD distribution separation between members and non-members.

## Main findings
- Author claim: dual-view access strictly increases available membership information when unlearning's behavioral impact differs by membership (Gain > 0 condition, Theorem 1).
- Author claim: unlearning affects unseen/non-member predictions more than memorized member predictions — an asymmetry that amplifies membership leakage for retained data.
- Author claim: DVIA effectively infers retained-data membership without training an attack model, using a lightweight likelihood-ratio module; UCD (black-box) tracks white-box influence scores closely.

## Design implications
"Verification access" is itself a privacy attack surface: letting a user compare pre- and post-deletion models to confirm forgetting can leak membership about everyone else's retained data. Relevant to any right-to-be-forgotten / data-deletion feature, including agent-memory and LLM unlearning.

## Implementation implications
Do not casually expose both original and unlearned model outputs to the requesting user. Consider serving only deletion attestations (not comparable model outputs), adding calibrated noise/DP, or limiting confidence granularity to shrink UCD signal.

## Evaluation implications
Unlearning privacy evaluations must include the *retained-data* membership risk under dual-view, not only forgotten-data leakage. The Gain > 0 condition (asymmetric behavioral impact) is a testable diagnostic for whether a given unlearning method amplifies leakage.

## Deployment implications
Machine-unlearning / data-deletion services should treat before/after model comparability as sensitive; couple deletion with differential privacy or output-perturbation and audit the dual-view exposure explicitly.

## Monitoring and incident implications
Log and rate-limit paired queries against original vs. unlearned endpoints on overlapping inputs; flag systematic before/after confidence-difference probing as a potential membership-inference campaign.

## Applicability boundaries
Demonstrated for image-classification models with confidence outputs under exact/approximate unlearning. Do NOT over-generalize the specific UCD numbers to LLMs, generative models, or label-only APIs without re-validation. The conceptual result (dual-view amplifies retained-data leakage) is broadly relevant to unlearning/data-deletion in AI systems, including agent memory.
