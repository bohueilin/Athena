## Research question
Why do targeted adversarial examples (AEs) crafted on a static model fail after a Class-Incremental Learning (CIL) model is updated with new classes, and how can AEs be made *sustainable* (still effective) across successive CIL updates?

## Problem definition
CIL models are updated sequentially with new-class data, causing domain drift of previously learned classes; this alters the direction/magnitude of perturbations needed to reach a target domain, so pre-crafted targeted AEs degrade into wrong-class or benign noise. The goal is a universal targeted perturbation delta that keeps misclassifying inputs to a fixed target class y_t across all model versions f_i (i >= 1).

## System or model being studied
Image classifiers under CIL: ResNet-32 on CIFAR-100 and ResNet-50 on ImageNet-100, each split into 10 tasks of 10 classes. Nine CIL algorithm families evaluated (Finetune, Replay, MEMO, DER, Foster, WA, BiC, iCaRL, PodNet). Attack uses a frozen CLIP visual-language model for semantic anchoring plus the initial CIL model f_1 as surrogate.

## Threat model
- Adversary objective: universal targeted misclassification to y_t that persists across CIL updates (sustainability).
- Adversary knowledge: gray/black-box. Adversary can access the *initial* CIL model f_1 and the full label set {y_t, Y_nt}; has NO access to the CIL training set, update process, or later models f_i (i>1) except black-box at inference.
- Adversary access: crafts one universal perturbation offline using f_1 + CLIP + a public out-of-distribution (POOD) dataset; applies delta to test inputs.
- Adversary capabilities: l-infinity-bounded universal perturbation.
- Attacker budget: epsilon = 32/255 (stated standard for black-box transferable attacks); filter threshold sigma = 0.7; single RTX 4060 8GB.
- Phase: offline perturbation optimization (training-time of the AE) + inference on updated victim models (deployment).
- Targeted / untargeted: targeted (untargeted excluded as trivially effective).
- Digital / physical: digital.
- Adaptive / non-adaptive: non-adaptive to CIL defenses; robust across CIL method choice, not attack-aware defenders.

## Trust assumptions
Assumes the initial model f_1 is accessible and that CLIP provides stable, generalizable target-class semantics; assumes public POOD data (Tiny-ImageNet for CIFAR-100; ImageNet-1K minus overlap for ImageNet-100) is available. Assumes gradient guidance from f_1 remains partially valid through CIL (via distillation/orthogonal projection preserving gradients).

## Attack or failure mechanism
Domain drift after updates moves class decision boundaries so surrogate-fit perturbations misalign. SAE counters drift by making AE semantics (a) similar to the target class and (b) distinguishable from all other classes, so they survive boundary shifts. Two failure sources addressed: overfitting to f_1's gradients, and non-target examples that accidentally carry target-class semantics (semantic fluctuation).

## Proposed defense or method
SAE (Sustainable Adversarial Examples) — an attack framework with two modules:
- Semantic Correction Module: uses CLIP text/image encoders to compute target (D_t), non-target (D_nt), and adversarial (D_adv) semantic directions; L_CLIP pulls perturbed examples toward y_t text and pushes from non-target texts; a CIL-based correction adds a Binary Cross-Entropy surrogate loss L_Surr on f_1 logits to keep optimization aligned to the target across evolving models.
- Filtering-and-Augmentation Module: filters POOD examples whose latent cosine similarity to averaged target embeddings exceeds sigma (confusing semantics), then applies random rotation/scaling/translation/patching augmentations to remaining examples to stabilize/generalize AE semantics.

## Datasets and benchmarks
CIFAR-100 (ResNet-32) and ImageNet-100 (ResNet-50), 10x10 task split, target class from first 10 classes. POOD: Tiny-ImageNet (200 classes) for CIFAR-100; ImageNet-1K (non-overlapping classes) for ImageNet-100. Baselines: MIFGSM, GAKer, AIM, CGNC, CleanSheet, UnivIntruder.

## Evaluation methodology
Optimize one universal delta on f_1 + CLIP + POOD, then measure attack success on each of the 9 CIL methods' final/intermediate models across 10 tasks. Averaged over ten target classes. Grad-CAM used to visualize shrinking target-contributing regions as classes grow.

## Metrics
- ASR: fraction of perturbed test examples classified as target by model f_i after task i.
- SASR (Sustainable ASR): average of I[f_i(x_j + delta) = y_t] over all M tasks and C examples — the paper's headline sustainability metric.

## Main findings
- Author claim: SAE improves average attack success by 31.28% after a 9-fold increase in class count.
- On CIFAR-100 (Table 1, AVG SASR across CIL methods): SAE 50.07 vs UnivIntruder 32.49, AIM 19.32, MIFGSM 21.64, CleanSheet 3.46, CGNC 0.17, GAKer 0.62.
- On ImageNet-100 (AVG SASR): SAE 29.71 vs UnivIntruder 2.11, MIFGSM 20.84, AIM 2.33 — SAE leads on average.
- Strong per-method results (e.g. CIFAR-100 PodNet SASR 85.30 vs next-best 44.17; ImageNet-100 PodNet 83.89 vs MIFGSM 68.02).

## Negative results
- SAE is not always top: on ImageNet-100 several columns MIFGSM beats SAE (e.g. Finetune 9.80 vs SAE 6.04; DER 26.23 vs SAE... note ImageNet-100 DER row shows AIM/MIFGSM higher in some cells). Generative baselines GAKer/CGNC/CleanSheet collapse to near-0 SASR, confirming the sustainability gap they aim to fill.
- Clean accuracy of the CIL models themselves varies widely (26-74%), bounding achievable attack ceilings.

## Additional limitations identified during review
_(reviewer synthesis)_
- Requires access to the initial model f_1 and label space; degradation if only much later models are accessible is not shown.
- Effectiveness hinges on CLIP's semantic coverage of the target class; rare/fine-grained targets untested.
- Only two datasets (CIFAR-100, ImageNet-100) and CNN backbones; transformer CIL victims and detection/segmentation not covered.
- No adaptive defense (e.g. adversarial-trained CIL, purification) evaluated against SAE; the "sustainability" is against benign CIL updates, not defenders.
- epsilon = 32/255 is relatively large (visible), weakening imperceptibility claims.

## Design implications
Novel threat axis for agent/ML security: adversarial inputs can be engineered to survive *model updates* (continual learning). Systems that rely on periodic retraining/fine-tuning as an implicit defense should not assume updates neutralize adversarial inputs — persistence across versions is achievable.

## Implementation implications
Continual-learning deployments (fraud, moderation, perception) should track adversarial robustness per model version, and consider purification/detection at inference rather than relying on drift to erode attacks.

## Evaluation implications
Introduces SASR: robustness/attack evaluations for updating models should be measured across the update trajectory, not only on a single snapshot. Adopt trajectory-averaged metrics.

## Deployment implications
Adjacent to agent security: relevant to any deployed model refreshed via incremental learning. Not demonstrated on LLM agents or tool pipelines.

## Monitoring and incident implications
Monitor for target-class prediction drift that *persists* after retraining as a signature of sustainable AEs; embedding-space (CLIP) anomaly detection is a candidate control.

## Applicability boundaries
Generalizes to targeted transfer attacks on CIL image classifiers. Do NOT generalize to prompt injection, tool abuse, or LLM-agent security, nor to untargeted attacks (explicitly out of scope). CLIP-dependent, epsilon=32/255 digital only.
