## Research question
Can a malicious passive party in Graph-based Vertical Federated Learning (GVFL) craft adversarial input embeddings that dominate joint inference (steering predictions to a target class and monopolizing contribution rewards) WITHOUT server-model access, model queries, or in-domain labeled auxiliary data?

## Problem definition
GVFL aggregates local node embeddings from multiple parties (one active party with labels + a server model; others passive) for node classification. Prior attacks (Graph-Fraudster, NA², Hijack) assume server-architecture access, query feedback, or in-domain labeled auxiliary graphs — unrealistic because the server model is proprietary and real auxiliary graphs exhibit cross-domain / class-space disparities. SGAC removes these assumptions.

## System or model being studied
GVFL node-classification system: each party P^i runs a local GNN embedding model M_e^i; embeddings are concatenated (H_cat) and fed to a server model M_s (owned by the active party) to predict ŷ = argmax(M_s(H_cat)). Attacker is one passive party.

## Threat model
- Adversary objective: craft adversarial input embedding H_A that dominates joint inference toward a target class l_tar regardless of benign inputs, and monopolize contribution-based incentive rewards.
- Adversary knowledge/access: NO access to server model M_s (structure, parameters, query predictions), other parties' test inputs H_B, or their embedding models; NO labeled training data. HAS its own train/test graph, its optimized embedding model M_e^A (including its shared gradients g^A), and a labeled auxiliary graph G_aux from a NON-training domain whose broader class space C_s ⊇ target class space C_t (exact overlap unknown).
- Adversary capabilities: train a surrogate ("proxy") of the server model from auxiliary data; adversarially perturb its controlled test embedding.
- Attacker budget: labeled auxiliary-graph volume studied (Fig. 2a); PGD-style optimization with T iterations over |Q| shadow graphs.
- Phase: inference (dominating joint inference); surrogate trained offline beforehand.
- Targeted / untargeted: targeted (drive to l_tar).
- Digital / physical: digital.
- Adaptive / non-adaptive: evaluated under three defenses/countermeasures.

## Trust assumptions
Insider adversary within a federated consortium follows the protocol but is byzantine on its own input. Common nodes are assumed pre-aligned across parties (private set intersection). Attacker retains its own gradients from GVFL training (used for surrogate fidelity).

## Attack or failure mechanism
GVFL integrates all parties' embeddings, so a single perturbed input can skew the aggregated prediction while suppressing benign parties' influence (measured by a saliency score = ℓ1-norm of derivative of output variance w.r.t. H_B). This "adversarial dominating input" both flips predictions and negates benign contribution, hijacking the incentive/reward mechanism.

## Proposed defense or method
SGAC (attack framework), two modules:
1. Surrogate Generation — learns a high-fidelity surrogate of the server model from out-of-domain auxiliary graphs via domain-adversarial training (Ganin et al.): generalized embedding learning using high-order co-occurrence (random-walk PMI matrix P replacing adjacency) + class-attention convolution; a multi-task domain discriminator with |C_s| class-specific heads for conditional alignment; class-transferability weighting w to down-weight outlier classes; self-training with pseudo-labels; and a gradient-similarity loss forcing the surrogate's gradients to match the attacker's retained server gradients. Min-max optimization.
2. Adversarial Crafting — builds a diverse, contribution-emphasized "shadow input set" S using Grad-CAM-style saliency over node features/edges (percentile masking), then runs a PGD-style attack (with box constraints + momentum) approximating benign-party saliency via finite-difference (FDM) to produce transferable, contribution-monopoly perturbations.

## Design implications
Contribution/incentive mechanisms in federated ML are an attack surface: an insider can both flip outputs and null benign contribution to monopolize rewards. Surrogate models can be built from out-of-domain data via domain adaptation, undermining "proprietary server model" as a security assumption.

## Implementation implications
Federated aggregation should bound any single party's influence on joint inference (e.g., robust aggregation, contribution auditing) rather than relying on server-model secrecy. Reward/incentive schemes need manipulation-resistance.

## Evaluation implications
GVFL defenses should be tested against out-of-domain-surrogate attackers and adaptive adversaries targeting the incentive layer, not only in-domain query-based attackers.

## Deployment implications
Relevant to cross-silo federated deployments (e-commerce, traffic, medical graphs) with incentive rewards. Insider (compromised passive party) is the realistic adversary; server-model secrecy provides limited protection.

## Monitoring and incident implications
Suggests monitoring per-party contribution/saliency distributions and anomaly-detecting dominating inputs; the saliency-suppression signature could itself be a detection feature.

## Applicability boundaries
Scope: graph-based vertical federated learning node classification with contribution incentives. Should NOT be generalized to horizontal FL, non-graph VFL, or LLM/agent systems directly. Adjacent to agent security: transferable lessons on surrogate-model theft, out-of-domain transfer attacks, and multi-party contribution gaming — not core LLM/agent/tool security.
