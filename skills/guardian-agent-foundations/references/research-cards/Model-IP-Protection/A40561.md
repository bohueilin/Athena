## Research question
Can a latent-diffusion text-to-audio (TTA) model's generated audio be reliably attributed to its source model without additional training and without degrading audio quality — by embedding a watermark into the model's initial latent and recovering it via inversion, robustly enough to survive common audio distortions?

## Problem definition
Latent-diffusion TTA models raise attribution needs (voice-imitation fraud, synthetic-media misinformation). Existing audio watermarking falls into three categories, each limited: (1) post-processing embedding degrades quality; (2) vocoder fine-tuning (e.g., HiFi-GANw) is not scalable across vocoder architectures; (3) codec-based methods need trained encoder/decoders. All show limited robustness to resampling/pitch-shift, etc. Directly embedding a watermark in the initial latent and recovering via DDIM inversion fails because the mel-spectrogram↔waveform conversion is lossy and forward/reverse (CFG vs unguided) process mismatch causes accumulating inversion error.

## System or model being studied
Anchor Watermark: an anchor-based inversion-optimization attribution framework for latent TTA models (AudioLDM, AudioLDM2, Tango, Tango2). Embedding: binary watermark bits w reshaped to latent dimensionality, encrypted with ChaCha20 → pseudorandom w_r, then distribution-preserving sampling maps them into the Gaussian initial latent z_T (the "pivotal anchor"), so generated audio inherently carries the watermark; the encryption key and model parameters are held only by the model owner; users access generation via a public API. Extraction: convert audio → mel → latent z0', DDIM-invert toward z_T', recover bits via inverse mapping. Robust extraction reformulates inversion as a time-series optimization: unguided denoising from the pivotal anchor yields an anchor trajectory Z*; the inverted trajectory Z' is aligned to Z* via Soft-DTW loss with gradient descent, reducing accumulated error. Attribution succeeds when bit accuracy Acc(w, w') > threshold τ.

## Threat model
- Adversary objective: Evade attribution / strip provenance of generated audio (or falsely disclaim model-generated audio) via signal distortions; broader harm motivation is voice-cloning fraud and misinformation.
- Adversary knowledge: Black-box w.r.t. the owner's secret ChaCha20 key and model parameters (users only see a public generation API); adversary can apply arbitrary audio post-processing.
- Adversary access: Post-generation audio manipulation (distortions).
- Adversary capabilities: Ten distortion types evaluated — 32 kHz resampling, 100 Hz high-pass, 1000 Hz low-pass, 10% amplitude scaling, 9 kbps MP3, 8-bps recount, 15-sample median filter, 5 dB Gaussian noise, 60% cropping, semitone (0.5) pitch shift.
- Attacker budget: Not quantified; distortions applied at fixed and varied intensities (ablation).
- Phase (training / inference / deployment): Inference/deployment (training-free; watermark is embedded at generation via the initial latent, recovered post-hoc).
- Targeted / untargeted: Untargeted evasion (distortions).
- Digital / physical: Digital (audio signal processing; no over-the-air/physical channel tested).
- Adaptive / non-adaptive: Non-adaptive — distortions are generic signal operations, not watermark-aware adversarial optimization.

## Trust assumptions
- The ChaCha20 encryption key and model parameters are exclusively held by the model owner; users interact only through a public API. Attribution and false-positive control depend on this secrecy.
- Assumes the owner can run inversion + anchor-trajectory optimization on the suspect audio (white-box owner access to the candidate model and its predefined anchor).
- Assumes latent trajectories of CFG (λ=7.5) and unguided (λ=1) diffusion remain statistically close across steps (supported by a reported K-S test, consistent at most steps under a 0.05 threshold).

## Attack or failure mechanism
Primary failure mode being solved is not an active attack but inversion error accumulation: (a) lossy waveform↔mel conversion (STFT + mel filter bank discards high-frequency/phase info) distorts z0' away from z0^w; (b) condition mismatch — generation uses CFG (λ>1, prompt c≠∅) while inversion uses λ=1, c=∅ — compounds per-step error. These make direct-inversion watermark recovery unreliable. Adversarial distortions (Table 1) further stress robustness.

## Proposed defense or method
Anchor-based inversion optimization: (1) Embed via distribution-preserving sampling of encrypted bits into the initial latent (pivotal anchor), leaving generation unchanged. (2) For attribution, run unguided denoising from the pivotal anchor to produce a deterministic anchor trajectory Z* whose intermediate latents closely resemble the CFG generation trajectory. (3) Optimize the inverted trajectory Z' toward Z* at each timestep using Soft-DTW loss (probabilistic alignment over all warping paths, unlike pointwise MSE), via backward-DP gradients and Adam (lr=0.01, 3 iters/timestep). (4) Recover bits from the refined final latent; declare attribution when bit accuracy exceeds τ. Multi-anchor case: optimize against each of N anchors and take argmax bit-match as attribution; FPR is derived as a function of τ and N.

## Datasets and benchmarks
- TTA models: AudioLDM, AudioLDM2, Tango, Tango2 (four open-source diffusion T2A models).
- Datasets (prompts/audio): AudioCaps, WavCaps, MusicCaps (three benchmarks).
- Setup: DDIM sampler, 50 steps, 8 s audio, 256-bit watermark; inversion with empty prompt (c=∅), guidance scale 1; RTX 4090.
- Baselines: post-processing (FSVC, NormSpace, Patch, AudioSeal, WavMark, Timbre), fine-tuning (HiFi-GANw), codec-based (GROOT).

## Evaluation methodology
Generate 1,000 watermarked samples (AudioLDM + AudioCaps) per method; measure attribution under clean audio and ten distortions; compare against 8 baselines. Quality/bias assessed via t-test on FAD and IS against watermark-free audio. Ablations vary distortion intensity, guidance scale (4–18), sampling steps (10–100), and ODE samplers (LCM, PNDM, DEIS, DPMSolver).

## Metrics
- True Positive Rate (TPR) at a fixed False Positive Rate (FPR).
- Bit accuracy (Bit Acc) of recovered watermark.
- Audio quality: Fréchet Audio Distance (FAD) and Inception Score (IS); t-value quantifying watermark-induced performance bias vs watermark-free audio.

## Main findings
- (Author claim) Training-free attribution that leaves generative performance unaffected, across 4 TTA models and 3 datasets; TPR reaches 100% on clean audio with only minor drops under attack.
- (Author claim, Table 1) Average TPR 98% and Bit Acc 99% across the ten distortions — substantially above baselines; many baselines (Patch, Norm, Timbre, WavMark, AudioSeal) fail under most attacks; GROOT is the strongest baseline but still lags (reported avg TPR 16% / Bit Acc 19% in the robustness-against-distortions comparison).
- (Author claim) Lowest quality bias: Ours FAD 2.31 with the smallest t-values among methods (2.31/1.68 and 7.59/0.30 for FAD/IS bias), indicating minimal perceptual impact.
- (Author claim, ablation) Robust across guidance scales, step counts, and multiple ODE samplers; even worst case (high-intensity pitch shift) retains ~85% Bit Acc and ~93% TPR.

## Negative results
- Pitch shift is the hardest distortion — performance "drops significantly at higher intensities" (still ~85% Bit Acc / ~93% TPR).
- Direct inversion (without anchor optimization) is explicitly shown to lack robustness (motivating the method).

## Limitations stated by the authors
- Direct inversion fails; robustness requires the added optimization step (extra compute at attribution time — 3 optimization iterations per timestep).
- Pitch-shift robustness degrades at high intensity.
- The authors note interest in extending anchor-based sequence optimization to broader generative watermarking (image/video), implying current scope is audio.

## Additional limitations identified during review
_(reviewer synthesis — clearly not author claims)_
- **Owner-white-box, non-adaptive threat model**: attribution needs the owner's model, anchor, and key, and evaluates only generic signal distortions — not watermark-aware adaptive removal (e.g., diffusion-purification/regeneration attacks, or an adversary who re-diffuses the audio), nor forgery/spoofing of anchors.
- **FPR scales with number of anchors N** (owner acknowledges FPR(τ,N) grows with N); large-scale per-generation unique watermarks may inflate false attributions or verification cost (optimize-against-each-anchor is O(N)).
- **Compute cost at verification**: per-timestep Soft-DTW optimization over a 50-step trajectory for each candidate anchor is heavier than one-shot detectors.
- **No cross-model collusion / transfer analysis**: whether a different model's inversion could match the anchor is only partially addressed via the "correct-anchor-only" alignment claim.

## Design implications
- Embedding provenance into the initial latent (rather than post-processing the output) keeps generation quality intact and requires no retraining — a reusable pattern for provenance in latent-diffusion generators (audio and, prospectively, image/video).
- Treating inversion-error reduction as trajectory alignment (Soft-DTW to an unguided-diffusion anchor) is a transferable robustness technique for any invertible-diffusion watermark.

## Implementation implications
- Requires owner custody of a secret key (ChaCha20) and model parameters; verification requires running inversion + optimization against candidate anchors.
- Latent-space, distribution-preserving embedding avoids audible artifacts (validated by low FAD/IS bias t-values).

## Evaluation implications
- Audio-watermark robustness must be tested across a distortion suite (resampling, filtering, MP3, cropping, pitch shift) and at multiple intensities; pitch shift is a good stress test.
- Report both attribution rate (TPR@FPR) and generation-quality bias (FAD/IS t-tests) to show the watermark is imperceptible.

## Deployment implications
- Fits model owners offering TTA via a public API who need after-the-fact attribution of suspect audio. Attribution is owner-side and compute-bearing; not a lightweight client-side detector.
- Provenance for synthetic audio supports anti-fraud (voice cloning) and misinformation tracing use cases named by the authors.

## Monitoring and incident implications
- Enables an owner to answer "did my model generate this audio?" as forensic evidence in a dispute; multi-anchor design can attribute to a specific generation instance, aiding incident attribution (with the FPR(τ,N) caveat).

## Applicability boundaries
_(where these findings should and should NOT be generalized)_
- **Adjacent to agent/LLM security**: it is generative-media provenance/attribution, transferable in principle to agent-produced media, but it is specific to latent-diffusion TTA and does not concern LLM/agent/tool/prompt security. Robustness claims apply to the tested non-adaptive signal distortions only — do NOT generalize to watermark-aware or regeneration/purification attacks, nor to physical (over-the-air) channels, which were not evaluated.
