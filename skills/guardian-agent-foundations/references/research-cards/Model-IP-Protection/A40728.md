## Research question
Can Embedding-as-a-Service (EaaS) copyright protection be made robust simultaneously against all three known watermark-evading attack families — CSE (cluster-and-remove), paraphrasing, and dimension-perturbation — rather than resisting only a subset as prior watermarks do?

## Problem definition
EaaS APIs (e.g., OpenAI text-embedding-3-large) return embeddings for a fee and are vulnerable to model-extraction: a stealer queries the provider, collects output embeddings, and trains a surrogate model to offer a cheaper competing service, causing economic loss. Existing watermark defenses each fail against at least one attack: trigger-word methods (EmbMarker, WARDEN, EspeW) are broken by paraphrasing (trigger words carry no semantics); the linear-transformation method (WET) resists paraphrasing but is broken by dimension-perturbation (removing/permuting/shifting dimensions) because its detection assumes fixed dimensions and order. Since an attacker who defeats any single attack defeats the defense, comprehensive protection is needed (Table 1 summarizes each method's gaps).

## System or model being studied
RegionMarker: a region-triggered semantic watermarking framework for EaaS. Three stages: (1) Trigger Region Definition — project provider embeddings to a low-dimensional space via a secret dimensionality-reduction matrix (PCA), then partition via Locality-Sensitive Hashing (LSH, random orthogonal hyperplanes) into 2^d regions; randomly sample R = α·2^d regions as trigger/watermark regions. (2) Semantic Watermark Injection — assign each trigger region r a unique watermark embedding w_r (embedding of a target sample); if a text's reduced embedding falls in region a_r, return e_p = Norm((1-λ)·e_0 + λ·w_r), where λ controls watermark strength; using the text-embedding-derived watermark resists dimension-perturbation. (3) Copyright Verification — build a backdoor corpus (texts in watermark regions) and a benign corpus; compare cosine-similarity / squared-L2 distance distributions to w_r; a Kolmogorov–Smirnov (KS) test p-value (with Δcos, Δl2 as supplementary) declares infringement conservatively (any watermark level flagging → infringement).

## Threat model
- Adversary objective: Steal (extract) the EaaS model via queries to build a competing surrogate, and evade watermark-based copyright detection.
- Adversary knowledge: Black-box query access to the provider's embedding API. The secret dimensionality-reduction matrix and the chosen trigger regions are known only to the provider (so the attacker cannot identify/remove watermarks).
- Adversary access: Query the API, collect embeddings, train a surrogate; then apply watermark-removal transforms.
- Adversary capabilities: Three attack families — CSE (cluster embeddings, select suspicious samples, remove principal components), paraphrasing attacks (NLLB translation-based; gpt-4o-mini rewriting), and dimension-perturbation (dimension-shift, dimension-reduction/removal, permutation).
- Attacker budget: Not quantified beyond querying + surrogate training.
- Phase (training / inference / deployment): Inference/deployment — extraction via API queries; watermark verification post-hoc on the suspect (extracted) model's outputs.
- Targeted / untargeted: Targeted evasion of the specific watermark.
- Digital / physical: Digital.
- Adaptive / non-adaptive: Semi-adaptive — evaluated attacks are watermark-removal techniques designed to bypass EaaS watermarks (CSE is watermark-aware); however attacks are not specifically optimized against RegionMarker's secret-region design.

## Trust assumptions
- The dimensionality-reduction matrix and the set of trigger regions are secret to the provider; security rests on the attacker being unable to recover them.
- Provided embeddings must retain utility comparable to originals (verified via downstream MLP task accuracy).
- The surrogate model trained on watermarked embeddings inherits the watermark behavior (standard EaaS-watermark assumption).
- Verification requires provider-controlled backdoor/benign corpora and access to the suspect model's output embeddings.

## Attack or failure mechanism
Prior failures: (a) trigger words are semantically empty → paraphrasing removes them; (b) WET's linear transform assumes stable dimension identity/order → shifting/removing/permuting dimensions evades detection; (c) directly partitioning high-dimensional space gives extremely uneven region occupancy (Fig. 3: SST-2 embeddings cluster in few of 16 regions), enabling CSE to isolate/strip watermarks. RegionMarker counters: dimensionality reduction yields uniform region occupancy (harder for CSE), semantic regions survive paraphrasing, and using the text embedding itself as the watermark (across the whole region) resists dimension-perturbation.

## Proposed defense or method
Region-triggered semantic watermarking (above): secret PCA projection + LSH region partition + per-region unique watermark embeddings blended into in-region text embeddings; verification via KS-test p-value on cosine/L2 distributions (backdoor vs benign), combined conservatively across watermark levels. Design intent: uniform region occupancy defeats CSE; semantic (region-level) triggers defeat paraphrasing; embedding-as-watermark defeats dimension-perturbation — i.e., comprehensive defense against all three attack families (Table 1).

## Datasets and benchmarks
- SST-2 (sentiment), AG News (news, classification/recommendation), Enron (spam), MIND (news recommendation) — four datasets.
- Task-utility classifier: MLP on EaaS embeddings.
- Baseline defenses: WARDEN, EspeW, WET (and prior EmbMarker context).
- Attacks: CSE; paraphrasing via NLLB and gpt-4o-mini; dimension-shift and dimension-reduction.

## Evaluation methodology
For each defense, measure task performance (ACC, F1) and detection performance (KS p-value, Δcos, Δl2) under No-Attack and each of the four/five attacks; a p-value < 0.05 counts as successful copyright protection ("COPY?" ✓/✗). Compare which methods succeed across all attacks (Table 2 for SST-2; more datasets referenced).

## Metrics
- Task utility: classification Accuracy (%), F1-score.
- Detection: KS-test p-value (↓ better), Δcos (cosine-similarity difference, ↑ better for defender), Δl2 (squared-L2 difference, ↓), and a binary COPY? protection outcome (p<0.05 → protected).

## Main findings
- (Author claim, Table 2 / Table 1) RegionMarker is the only method achieving successful copyright protection (✓) across all evaluated attacks on SST-2: No-Attack, CSE, paraphrasing (NLLB and gpt-4o-mini), dimension-shift, and dimension-reduction — while WARDEN and EspeW fail under paraphrasing, and WET fails under dimension-perturbation.
- (Author claim) Task utility is preserved: RegionMarker maintains ~92–94% accuracy comparable to baselines under attacks (e.g., 93.23% no-attack; 92.35% under gpt-4o-mini paraphrasing).
- (Author claim) Dimensionality reduction is essential: without it, embedding occupancy across regions is highly uneven (Fig. 3), making effective trigger-region selection and CSE-resistance impossible.
- (Author claim) Extensive experiments on four datasets confirm effective, comprehensive defense.

## Additional limitations identified during review
_(reviewer synthesis — clearly not author claims)_
- **Security rests on secret-region/matrix secrecy**: no analysis of what happens if the PCA matrix or trigger regions are partially inferred (e.g., an attacker who estimates the provider's PCA basis from many queries); robustness against a RegionMarker-aware adaptive attacker (jointly attacking regions + dimensions) is not shown.
- **Verification needs provider-side control**: requires constructing backdoor/benign corpora and access to suspect-model outputs — offline, provider-driven, not a live monitor.
- **Utility drop under CSE** is visible (e.g., ACC falls to ~87.9% under CSE), and the watermark-strength λ trades off utility vs detectability; the sweet spot may be dataset-dependent.
- **Combined/stacked attacks** (e.g., paraphrase then dimension-shift then CSE) are not reported in the extracted tables; real attackers "attempt various attacks."
- **Only classification/recommendation text tasks** tested; generalization to retrieval/RAG embedding use is unverified.

## Design implications
- Using **semantic regions** (LSH over a secret low-dimensional projection) rather than surface trigger words makes a backdoor watermark survive paraphrasing — a reusable idea for provenance that must withstand rewriting.
- Using the **text embedding itself** as the region's watermark (spread across the whole region) defeats dimension-perturbation attacks that break fixed-dimension linear-transform watermarks.
- Uniform region occupancy (via dimensionality reduction) is a prerequisite for CSE-resistance — an important, non-obvious design constraint.

## Implementation implications
- Provider must keep the dimensionality-reduction matrix and trigger-region selection secret; watermark strength λ and region ratio α tune the utility/detectability trade-off.
- Verification is an offline statistical test (KS on cosine/L2 distributions) over provider-built backdoor/benign corpora against the suspect model's outputs.

## Evaluation implications
- EaaS/embedding-watermark defenses should be evaluated against the full attack matrix (removal/CSE, paraphrasing, dimension-perturbation) jointly, because defeating any single attack defeats the defense; single-attack robustness overstates protection.
- Report task utility alongside detection to show the watermark does not cripple the embedding service.

## Deployment implications
- Directly applicable to commercial EaaS providers defending against model-extraction/imitation and surrogate-service competition — an API-boundary IP-protection control.
- Because embeddings power RAG/agent memory/retrieval, provenance on embedding APIs is relevant to securing the AI supply chain that agents consume.

## Monitoring and incident implications
- Provides a forensic test to establish that a competing embedding service was extracted from the provider's model (evidence for enforcement), though it is post-hoc rather than a real-time extraction monitor.
