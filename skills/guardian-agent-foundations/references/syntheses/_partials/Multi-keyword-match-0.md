# Partial Synthesis — Multi-keyword-match, chunk 0 (40 papers)

Scope: papers A36972, A36989, A36993, A36994, A36995, A37005, A37023, A37327, A37345, A37434, A37452, A37507, A38085, A38124, A38163, A38268, A38470, A38526, A38544, A38606, A38653, A38870, A39184, A39192, A39335, A39342, A39344, A39363, A39451, A39546, A39573, A39617, A39670, A39812, A39833, A39856, A40004, A40118, A40188, A40189. All are AAAI-26 papers.

> Evidence-integrity note: every claim below traces to a specific paper's research card. Numbers are author-reported unless flagged. "Reviewer synthesis" marks cross-paper observations that are the analyst's, not any single paper's claim. Calibrated language is used throughout ("demonstrated under the evaluated threat model", "reduced ASR against the tested attacks", "not evaluated against"). This is a keyword-matched bucket, so a substantial fraction of the chunk is peripheral to agent security; that is itself a finding, not a defect.

## Chunk character (reviewer synthesis)
This is a "multi-keyword-match" harvest: papers collided on generic tokens ("adversarial", "robustness", "attack", "agents", "privacy", "federated", "contrastive", "fusion"). Consequently the chunk splits into three tiers:
- **Core agent/LLM security (small):** A40004 (LLM prompt inversion), A40189 (LLM-guided programmatic-agent adaptation with sandbox/rollback/provenance), and — as agent-architecture attack surface, though with no threat model — A40188 (personalized web agent) and A39812 (federated LLM multi-agent workflow synthesis).
- **Adjacent ML-security / adversarial-ML (largest):** extraction/inversion (A36972, A37345, A39192), guardrail/jailbreak bypass (A36989), RAG/evidence poisoning (A37023), data/profile poisoning (A38606), federated-training security (A39184), adversarial-example robustness (A37434, A37452, A39335, A39363, A39451, A39833, A39856), physical adversarial perception (A38085), covert channel/steganography (A37327), biometric/device identity (A37005), watermarking/provenance & anti-misuse (A38268, A37507), confidential computation (A39670), multi-agent Byzantine robustness (A39344), and defensive SOC/agent-failure tooling (A36994, A36993).
- **Peripheral / off-topic (many):** benign methods whose "adversarial"/"robustness"/"privacy" is non-security — GAN training (A38544, A39342), domain adaptation (A38870), network-science robustness with "dual agents" = RL policies (A38470), trajectory/KG/recommendation representation learning (A38526, A38653), federated graph learning where privacy is asserted-but-never-tested (A38124, A39546, A39573, A40118, A39617), and forensics (A36995).

## Dominant threat models
1. **White-box / open-weights extraction & inversion.** Several papers assume the adversary holds the model or its outputs and reconstructs training data or hidden inputs: SIDE extracts training images from (even *unconditional*) diffusion models under white-box access (A36972); CLIP-FTI inverts a leaked face-recognition template into an impersonation-capable face under black-box transfer (A37345); TabGeoFlow studies black-box shadow membership inference against tabular synthesizers (A39192); Inv2A recovers hidden user/system prompts from an LLM's *text outputs* by reusing the model's own latent space, under white-box access to open-weight models (A40004). Reviewer synthesis: the shared lesson is "a released model/artifact is an extractable index of its private inputs" — capability is not confidentiality.
2. **Guardrail / input-filter evasion.** AMA crafts benign-looking prompts that pass NSFW text filters (incl. a GPT-4o filter) yet drive identity-preserving T2I models to emit identity-bound NSFW content via attribute misbinding — a text→image transformation that the input filter cannot see (A36989).
3. **Retrieval / data-stream poisoning.** DRIFTBENCH models GenAI-driven claim diversity plus adversarial evidence contamination of a retrieval-augmented fact-checker (A37023); CREAT poisons individual users' interaction histories to promote a target item while evading distribution-shift detectors (A38606). Reviewer synthesis: both attack the *ingestion boundary* and defeat single-granularity detectors.
4. **Federated / distributed-training adversaries.** LSHFed models poisoning (label-flip, gradient noise), gradient-inference/privacy, and role-election takeover with up to 50% collusive clients (A39184); DeMABAR models adaptive reward-corruption and Byzantine agents (α<1/2) in decentralized bandits (A39344).
5. **Inference-time evasion (adversarial examples).** A37434 (3D point clouds), A37452 (CLIP test-time), A39335 (multimodal), A39833 (SNNs), A39856 (universal perturbations on CNNs), and physically A38085 (vehicle camouflage fooling detectors *and* humans).
6. **Confidentiality against an untrusted host.** ReBoot performs fully-encrypted non-interactive MLP training under CKKS; the adversary is an honest-but-curious compute host without the secret key (A39670).
7. **Operating-environment adversary (agent defends).** TAPA's programmatic agent faces evolving/adversarial environments (DDoS botnets, swarm disturbances) and re-synthesizes symbolic programs online (A40189).

Reviewer synthesis on a recurring gap: a large sub-group *invokes* a threat vocabulary but models **no adversary at all** — the "privacy" of federated graph papers (A38124, A39546, A39573, A40118, A39812) is pure data-locality, asserted and never tested with a membership-inference/gradient-inversion attacker; the "adversarial"/"robust" of A38544, A39342, A38870 refers to GAN dynamics or domain adaptation.

## Major attack families
- **Training-data reconstruction / model inversion / membership inference:** A36972 (diffusion extraction via surrogate conditioning), A37345 (FR template inversion, 1-shot black-box transfer), A39192 (shadow MIA on tabular synthesis), A40004 (prompt inversion from outputs).
- **Guardrail bypass / jailbreak-style content evasion:** A36989 (attribute-misbinding prompts, author-reported +5.28% filter-bypass over baseline sets).
- **Data / evidence / profile poisoning:** A37023 (retrieval contamination), A38606 (stealthy profile pollution, adaptive RL), A39451 (graph-structure poisoning via Metattack/PGD), A39363 (label noise, framed as data-quality not strategic poisoning), A39184 (label-flip / gradient-noise poisoning in FL).
- **Adversarial examples / evasion:** A37434, A37452, A39335, A39833, A39856 (digital); A38085 (physical camouflage, human-stealthy).
- **Byzantine / corruption in multi-agent learning:** A39344 (reward corruption + Byzantine messaging), and as the poisoning threat family A39184.
- **Covert channel / exfiltration:** A37327 (robust neural-network steganography hiding secrets in AI-generated images).
- **Impersonation / forgery / provenance manipulation:** A37345 (biometric impersonation), A38268 (signature reuse/forgery, the defended threat), A36995 (image tampering, the detected threat).

## Major defense families
- **Confidential computation / crypto:** A39670 (CKKS FHE, end-to-end encrypted training); A39184 (secure-aggregation-style additive masking + LSH-hash gradient verification).
- **Robust aggregation / Byzantine tolerance:** A39344 (trimmed-mean per-arm filtering), A39184 (Hamming-distance outlier filtering + reputation-weighted role election).
- **Robust representation / robust optimization (evasion):** A37434 (fixed simplex-ETF head for inter-class separation), A37452 (test-time orthogonal-diverse counterattack over CLIP), A39335 (vagueness-calibrated gradient modulation), A39833 (temporal-ensemble adversarial training decorrelating cross-timestep vulnerability), A39363 (information-bottleneck clean/noise disentanglement), A39451 (acyclic-aggregation GNN that also blocks perturbation propagation).
- **Detection / runtime monitoring:** A37452 (directional-sensitivity score as clean/adversarial discriminator), A36994 (LLM Graph-of-Thought alert reduction + attack-path narrative), A36993 (unsupervised per-agent failure attribution).
- **Guardian-pattern runtime enforcement (the standout):** A40189 (TAPA) — LLM *proposes* symbolic programs, **shadow simulation verifies** before live replacement, a degradation threshold + **backup meta-policies decide/rollback**, an **Alert primitive routes to human approval**, and a **provenance chain** logs every adaptation for audit. Reviewer synthesis: this is the only paper in the chunk instantiating the full "models propose, environments verify, gates decide, traces prove" loop, decoupling LLM capability from live authority.
- **Content provenance / watermarking / anti-misuse:** A38268 (generative signature watermark binding metadata + one-time-use), A37507 (targeted protective perturbation redirecting unauthorized diffusion fine-tuning, with a traceable target-concept signature), A36995 (weakly-supervised tamper localization).

## Strongest replicated findings (cross-paper, reviewer synthesis)
- **"Non-conditioned / non-prompted therefore private" is false.** A36972 shows even *unconditional* diffusion models leak training data via surrogate conditioning; A40004 shows prompts leak from *outputs alone* (not just logits). Convergent: absence of an obvious conditioning/observation channel does not remove extraction risk.
- **Embeddings/templates are invertible into PII and impersonation surrogates.** A37345 (face templates) plus A40004 (prompt latent reuse) support treating stored embeddings/templates as high-sensitivity secrets, not innocuous features.
- **Single-granularity / single-stage filters are bypassable.** Input-only text filters (A36989), aggregate distribution-shift detectors (A38606), and lightweight output perturbations (A40004 reports these give "limited protection") each fail when the adversary transforms benign-looking inputs downstream or edits at a finer granularity.
- **Empirical adversarial robustness correlates with representation-space geometry.** A37434 reports Pearson r=0.96 between robustness and feature-space disentanglement (author-reported); A37452, A39363, A39451, A39833 independently improve robustness by shaping/decorrelating representations. Convergent theme, though each is single-team.
- **Robust aggregation tolerates a bounded malicious fraction.** A39184 (up to 50% collusive, author-reported) and A39344 (α<1/2 Byzantine, with regret bounds) agree that statistical filtering/trimming survives a minority adversary but degrades past the threshold.

## Conflicting / tension findings
- **DCR / shadow-MIA as a privacy signal.** A39192 relies on DCR (~50%) and a single black-box MIA to claim empirical privacy, while itself citing work ("On the Inadequacy of Similarity-based Privacy Metrics") arguing such metrics are inadequate — an unresolved internal tension the paper acknowledges.
- **"Robustness" is an overloaded word across the chunk.** A38163/A38124/A39573 mean *natural-corruption or non-IID* robustness; A38544/A39342 mean *GAN training stability*; A38870 means *domain adaptation*; only A37434/A37452/A39335/A39363/A39451/A39833/A39344/A38085/A39856 mean *adversarial* robustness. Reviewer synthesis: conflating these is the chunk's most common reporting hazard.
- **"Privacy-preserving" claimed vs. tested.** A39184/A39670 argue confidentiality with mechanisms and (respectively) honest-majority / RLWE-hardness assumptions; A38124/A39546/A39573/A40118/A39812 assert privacy purely from data-locality with *no* attacker-side evaluation. These are not directly contradictory but represent opposite ends of an evidence spectrum inside one keyword bucket.

## Defense bypasses / residual attack surface
- **Adaptive-attack gap is near-universal for the robustness papers.** A37452, A37434, A39335, A39833, A39451, A38606, A39184 are each evaluated against standard/non-defense-aware attacks; none run a fully adaptive attacker tailored to the specific defense objective. A39833 explicitly reports divergent per-attack rankings "suggesting gradient obfuscation" and mitigates with worst-case-over-attacks reporting, but still lacks a defense-adaptive attack. Reviewer synthesis: ensemble-diversity and randomized/test-time defenses (A39833, A37452) have historically been weakened by adaptive attacks, so these robustness numbers are "demonstrated under the evaluated, non-adaptive conditions" only.
- **Undetectability tested only vs. fixed detectors.** A37327's steganography evades *pretrained* SRNet/SiaStegNet but not a steganalyzer retrained on RFNNS stego (the realistic worst case).
- **Trusted anchors as single points of failure.** A39184 depends on a trusted Verifier that seeds the benchmark bit string; A40189 trusts the LLM synthesizer + RAG provenance store and shadow-sim fidelity; A39812's server-broadcast prototype graphs are an unauthenticated steering channel. Reviewer synthesis: each concentrates trust in a component whose compromise (poisoning, sim-to-real gap, malicious server) is unmodeled.
- **Honest-but-curious ≠ malicious.** A39670 provides confidentiality but no integrity/verifiability against a result-tampering host, and does not address the known CKKS approximate-decryption (IND-CPA^D) caveat on released values.
- **Filter/protection scoped to one stage.** A36989 adapts to text filters only (not output MLP/image filters); A37507 protects only pre-scrape images and is untested against purification/adaptive fine-tuners; A39451 defends structure attacks, not feature attacks.

## Benchmark / evaluation limitations
- **New benchmarks are valuable but generator-coupled.** DRIFTBENCH (16k instances, human-validated at 98.6% / κ=0.872 for real variants) is built with specific generators (GPT-4o, FLUX.1), risking generator artifacts confounding "diversity" effects, and uses live web retrieval (non-deterministic) (A37023). CREAT and its DBS-style setup depend on surrogate-transfer assumptions (A38606). DAWN introduces a single self-made benchmark (DBS), limiting external validity (A39812).
- **Judge/metric fragility.** ABSS (A36989) and DRIFTBENCH's reasoning scoring (A37023) use MLLM/VQA judges that are themselves gameable; A40188's LLM-as-a-Judge reward is a potential reward-hacking target (reviewer synthesis).
- **Surface-overlap metrics under-measure semantic harm.** A40004 uses TokenF1/BLEU, which miss semantic-but-non-verbatim recovery of private content.
- **Small / synthetic / single-model evaluations.** A39344 (single-laptop synthetic, K≤20), A39184 (10-client topology), A40004 (single 7B model, white-box), A38870 (N=10 cohort), A40189 (single 77.7%-uptime operating point) all limit generalization of headline numbers.
- **Truncation.** Many cards note result tables/appendices were truncated in extraction, so several per-model numbers are partial (flagged per card); this is a corpus-extraction limitation, not a paper defect.

## Recurring implementation patterns (reviewer synthesis)
- **Foundation-model reuse as the operative surface:** frozen SAM as a pseudo-label teacher (A36995); frozen CLIP/DINOv2 as offensive or defensive backbones (A37345 offensive, A37452 defensive, A38085 attack surrogate, A38163 semantic prior); the forward LLM reused as an inversion decoder (A40004). Reviewer synthesis: shared foundation models make attacks *transfer* across systems.
- **Contrastive / representation-shaping** appears in both benign (A38526, A38653, A38870) and security (A37005, A37452, A39363) papers; a keyword magnet, but for security it operationalizes "shape the feature geometry to resist perturbation."
- **Shadow/sandbox-before-live + rollback + provenance logging** (A40189) and **per-agent responsibility attribution over logs** (A36993) and **graph-grounded LLM incident narratives** (A36994) are directly reusable for an autonomy/trace console.
- **Selective / trust-weighted aggregation** (A39184 reputation election, A39344 trimmed mean, A38124/A39573/A39812 attention/affinity weighting) recurs — and the weighting itself becomes an attack surface whenever client-reported metrics are unauthenticated (reviewer synthesis, explicit in A39573/A39812 cards).

## Product / architecture implications for the Guardian stack
- **Treat model outputs, embeddings, prompts, and templates as confidential assets with access control + logging** — not innocuous features. Open-weights + secret system prompt served over one interface is an inversion risk (A40004); leaked FR templates are irreversible identity exposure (A37345); released generative models are extractable training-data indexes (A36972, A39192).
- **Harden the ingestion/retrieval boundary:** treat retrieved evidence and interaction history as untrusted, attacker-influenceable input; add near-dup/AI-generated-evidence detection, cross-source corroboration, and finer-than-aggregate anomaly monitoring (A37023, A38606).
- **Adopt the propose→verify→gate→prove loop** exemplified by TAPA (A40189): sandbox candidate agent actions, keep instant-rollback backups, route high-stakes cases to human approval, and log a tamper-relevant provenance chain — but *add* integrity/authenticity controls on the RAG/knowledge and synthesized code that TAPA leaves trusted.
- **For federated/multi-agent aggregation, authenticate client contributions and bound the malicious fraction** (A39184, A39344); do not treat data-locality as a privacy guarantee (A38124, A39546, A39573, A40118, A39812) or trust-weighting as poisoning-proof.
- **Physical-AI perception needs adversarial hardening + runtime anomaly detection, not human spot-checks**, because attacks can be human-stealthy (A38085) and empirical robustness is non-certified (A37434, A38163, A39833).
- **Confidential computation (HE) is viable for small models** as a TEE/DP complement, but pair with integrity/verifiable-computation and treat approximate-decryption leakage seriously (A39670).

## Open problems (as stated by papers + reviewer synthesis)
- **No demonstrated defense against LLM prompt inversion.** A40004 explicitly states it "fails to find a really valid schema to overcome LMI"; perturbation defenses are largely bypassed. (Author-stated open problem.)
- **Defense-adaptive evaluation is missing** across the robustness/steganography/poisoning papers (A37452, A37434, A39335, A39833, A39451, A37327, A38606, A39184) — the dominant open methodological gap (reviewer synthesis).
- **Attribution/accountability without an adversary model.** A36993 (multi-agent failure localization) and A36994 (SOC attack-path tracing) are not robust to log tampering / blame-shifting / evasion of the LLM reasoner — they are reliability tools, not yet security-grade accountability under adversarial logs (reviewer synthesis, echoed in both cards).
- **Federated agent-orchestration security.** A39812 operates on agent-to-agent topologies but tests only scale/heterogeneity "resilience," leaving update-inversion, subspace poisoning (its PR step amplifies rare directions), and server-prototype manipulation untested.
- **Provenance/verifiability without cryptographic binding.** A38268 enforces one-time-use signatures via watermark+metadata matching (not cryptographic non-repudiation) and assumes a trusted metadata store; forgery-resistance vs. skilled adaptive attackers is untested.
- **Persistent agent profiles as an unprotected asset.** A40188 concentrates LLM-inferred user data (incl. demographics) with no access control/minimization; the authors defer privacy to future work.

## Most load-bearing papers (by id, reviewer synthesis)
1. **A40004 (Inv2A / Language Model Inversion)** — core: hidden user/system prompts recoverable from LLM *text outputs*, data-efficiently, with an explicit (partial) defense evaluation showing perturbations are largely bypassed. Directly grounds "prompt confidentiality is an unmet security property."
2. **A40189 (TAPA)** — core: the chunk's only full runtime-enforcement pattern (shadow-sim verify → threshold gate → backup rollback → human-approval Alert → provenance chain) for LLM-moderated autonomous agents in adversarial environments.
3. **A37023 (DRIFTBENCH)** — the strongest RAG-security artifact here: a 16k human-validated benchmark for GenAI-diversity + adversarial evidence contamination against retrieval-augmented (L)VLM verification; establishes vulnerability of the retrieval/ingestion boundary.
4. **A39184 (LSHFed)** — most concrete distributed-training security design (poisoning-robust + privacy-respecting + communication-efficient aggregation, up to 50% collusion, with a structured security analysis under a trusted-verifier/honest-majority assumption).
5. **A38606 (CREAT)** — realistic, adaptive, stealth-constrained data/memory-poisoning that evades single-granularity detectors; the transferable meta-lesson for agent memory/history poisoning.
6. **A36972 (SIDE)** — reframes generative-model memorization: any conditioning (explicit or surrogate) amplifies extraction, refuting "unconditional = safe" and generalizing the training-data-reconstruction threat.

Secondary but useful for the trace-console/identity angles: A37345 (embedding/template inversion → identity assets), A36993/A36994 (agent-failure and attack-path attribution for the trace layer), A40188 (web-agent attack-surface catalog).
